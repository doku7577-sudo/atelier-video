# Atelier Vidéo

Transformez vos images en vidéos animées avec l'IA.

## Installation

1. Ouvrir le lien GitHub Pages sur mobile
2. Appuyer sur "Ajouter à l'écran d'accueil"

## Utilisation

1. Ajouter vos images
2. Écrire un prompt ou choisir un effet
3. Appuyer sur "Créer les vidéos"

## Clé API

Clé gratuite sur https://platform.agnes-ai.com
